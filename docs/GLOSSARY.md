# Terms

| Term | Meaning |
| --- | --- |
| Window overview | Searchable list of individual windows; Control–Option–Space opens it. |
| Switch | Bring the selected window to the front. |
| Left Half / Right Half | Arrange one window in the corresponding half of its display. |
| Maximize | Fill the usable display area, without entering full-screen mode. |
| Restore | Return to the frame saved before this session's first snap of that window. |
| Previews | Optional window pictures, refreshed on request and held in memory. |
| Accessibility | Required macOS permission to discover and control app windows. |
| Screen Recording | Optional macOS permission to capture preview pictures. |
